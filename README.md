RescueAI 🚨
Real-Time Survivor Detection & Emergency Alert System

"Not to replace human rescuers — but to give them Edge AI efficiency."

What is RescueAI?
A disaster-response Android app that uses on-device AI to detect survivors in real time and instantly alert the nearest rescue teams — even without internet.

Built for speed, built for the field. No cloud. No delay. No missed lives.

How it works
📷 Camera feed is processed live by a YOLOv8 model running directly on the phone
🔍 Survivors or hazards detected → alert fires automatically
📍 GPS captures exact location → nearest rescue team is notified
📡 No signal? SMS fallback sends distress signal anyway
🔐 Rescuers and survivors each get a separate, role-based interface via Firebase
