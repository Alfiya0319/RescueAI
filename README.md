# RescueAI: Real-Time Survivor Detection & Emergency Alert System

RescueAI is a high-efficiency, life-saving mobile application developed as part of the polytechnic diploma curriculum. It leverages Edge AI to empower and assist rescue teams during natural disasters by enhancing situational awareness and response efficiency through real-time survivor detection.

## 🚀 Key Features

- **Edge AI Survivor Detection:** Integrated and optimized a **YOLOv8** model inside a custom Android environment for real-time, on-device human/survivor and hazard detection with low latency.
- **Automated Alert System:** Designed robust logic to automatically initiate background triggers and manage responsive UI alert popups during critical survivor detection events.
- **Offline Hybrid Messaging:** Features a fail-safe SMS/Offline alert system to send instant distress signals even in low-network disaster zones.
- **Location-Based Tracking:** Integrates GPS services to capture precise coordinates and fetch nearby rescue team details based on proximity logic.
- **Role-Based Access Control:** Configured a secure backend using Firebase to handle separate interfaces and live data synchronization for both Survivors and Rescuers.

## 🛠️ Tech Stack & Tools

- **Frontend/OS:** Android Studio (Java/Kotlin)
- **AI Model:** YOLOv8 (Ultralytics)
- **Backend & Database:** Firebase Realtime Database
- **APIs & Gateways:** Twilio API / SMS Gateway, GPS Proximity Services

## 📌 Project Vision

> *"The objective of this project is not to replace human rescuers, but to provide them with Edge AI efficiency. If this technology saves even a single extra life, our implementation is successful."*
